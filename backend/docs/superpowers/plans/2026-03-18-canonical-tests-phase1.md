# Canonical Tests Phase 1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the runner, invariant validator, report generator, and 3 scenario fixtures (01-combate-basico, 02-magia-com-custo, 06-acao-invalida) that exercise the Lunaria RPG game engine against 3 AI models.

**Architecture:** A CLI runner calls MestreAgent directly (no websocket) with isolated Redis keys, saves structured logs as JSON. Vitest validates invariants from those logs. A report script compares results across models.

**Tech Stack:** Node.js ESM, Vitest, Redis (isolated prefix), MestreAgent + combateHelper + testeHelper from existing codebase.

**Spec:** `docs/superpowers/specs/2026-03-18-canonical-tests-design.md`

Also export a `runInvariants(log, cenario)` helper that runs only the invariants listed in `cenario.invariantes` and returns `{ passed, failed, results }`.

Key implementation notes:
- Iterate over `log.turnos`, checking `estadoAntes` and `estadoApos` for each
- For `mana_descontada_ao_usar_magia`: find the magia in `cenario.personagem.magias` by matching `gameIntent.magiaId`, compare `estadoAntes.jogador.mana - custo_mana === estadoApos.jogador.mana`
- For `dano_aplicado_quando_ataque_sucede`: only check when `resolucaoMecanica !== null && resolucaoMecanica.sucesso === true` and tipo is attack. Account for mitigation: if `resolucaoMecanica.danoCalculado === 0`, skip the HP check.
- For `alvos_referenciados_por_id`: check `gameIntent.alvo` matches an id in `cenario.inimigos`
- For `ia_nao_inventou_habilidade`: check `respostaIA.acoes` items — if they reference magia/habilidade, it must exist in `cenario.personagem.magias` or `cenario.personagem.habilidades`
- `ok` is always `falhas.length === 0`

### Task 4: Implement canonical-runner.js

**Files:**
- Create: `scripts/canonical-runner.js`

The runner is the most complex piece. It simulates a game session by calling MestreAgent directly.

- [ ] **Step 1: Write canonical-runner.js**

The runner must:

1. **Parse CLI args**: `node scripts/canonical-runner.js <cenarioId> [--model <model>] [--all]`
2. **Load fixture**: read from `tests/fixtures/scenarios/{cenarioId}.json`
3. **Generate runId**: `run_YYYYMMDD_HHmmss_XXXX` where XXXX is random hex
4. **Compute cenarioHash**: SHA-256 of fixture file content
5. **For each model** (or single model if `--model`):
   a. Create Redis session with isolated prefix `test_run_{runId}_{model}:`
   b. Build sessao object from fixture (personagem, estadoInicial, inimigos, historia)
   c. Instantiate MestreAgent via `criarMestreRPG()` with the model
   d. For each acao in fixture:
      - Capture `estadoAntes` from current session state
      - If `tipo === "iniciar_turno"`: call `mestre.narrarTurnoJogador()`
      - If `tipo === "mensagem"`: call `mestre.narrarAcaoStream()` with `gameIntent` mapped to `combatIntent` (the existing API uses combatIntent internally)
      - If `tipo === "rolar_dado"` and `quando === "se_solicitado"`: check if IA requested dice, auto-roll d20 with `Math.floor(Math.random() * 20) + 1`, resolve via `resolverTeste()`
      - Capture `respostaBruta` (raw string from model)
      - Parse response via `parseIAJson()`
      - If combat action: call `resolverMecanicaCombate()` to get `resolucaoMecanica`
      - Update session state (HP, mana, cooldowns, status)
      - Mark entities with `hp === 0` as `status: ["derrotado"]`
      - Capture `estadoApos`
      - Record timing (`tempoRespostaMs`, `tempoTurnoTotalMs`)
      - Check `condicoesDeParada`
   e. Build log object per spec Section 6
   f. Save to `tests/fixtures/frozen/{cenarioId}/{modelSlug}.json`
   g. Cleanup Redis keys

**Model mapping for CLI:**
- `groq` → `llama-3.3-70b-versatile`
- `gemini` → `gemini-2.5-flash`
- `sonnet` → `claude-sonnet-4-6`
- Default: runs all 3

**Important:** The runner must import from the real codebase:
```js
import { criarMestreRPG } from '../agents/Mestre/MestreAgent.js';
import { parseIAJson } from '../agents/Mestre/MestreAgent.js';
import { resolverMecanicaCombate, calcularHP, calcularMana, calcularEsquiva, calcularArmadura } from '../helpers/combateHelper.js';
import { resolverTeste } from '../helpers/testeHelper.js';
import { createClient } from 'redis';
import { createHash } from 'crypto';
```

**Error handling:**
- Wrap each turno in try/catch
- On AI timeout: record `erroParse: { tipo: 'timeout', mensagem: 'AI_TIMEOUT' }`, set `respostaParseou: false`
- On parse failure: record `erroParse` with tipo/mensagem/trecho
- On runner crash: set `statusExecucao: 'erro_execucao'`, `erroExecucao: { tipo, mensagem, stack }`
- Always cleanup Redis in finally block

- [ ] **Step 1: Write test file pattern**

All 3 test files follow the same pattern:

```js
import { describe, it, expect } from 'vitest';
import { runInvariants } from './invariants.js';
import { readFileSync, existsSync } from 'fs';
import { join } from 'path';

const CENARIO_ID = '01-combate-basico';
const cenario = JSON.parse(readFileSync(join(__dirname, '../fixtures/scenarios', `${CENARIO_ID}.json`), 'utf8'));
const MODELS = ['groq', 'gemini', 'sonnet'];

for (const model of MODELS) {
  const logPath = join(__dirname, '../fixtures/frozen', CENARIO_ID, `${model}.json`);

  describe(`${CENARIO_ID} [${model}]`, () => {
    if (!existsSync(logPath)) {
      it.skip(`log not found — run: node scripts/canonical-runner.js ${CENARIO_ID} --model ${model}`, () => {});
      return;
    }

    const log = JSON.parse(readFileSync(logPath, 'utf8'));
    const results = runInvariants(log, cenario);

    for (const [name, result] of Object.entries(results.results)) {
      it(name, () => {
        expect(result.falhas, result.falhas.join('\n')).toEqual([]);
      });
    }

    it('execution completed', () => {
      expect(log.statusExecucao).toBe('concluida');
    });
  });
}
```

Key detail: if frozen log doesn't exist yet, tests are skipped with helpful message. This allows running `npx vitest` before the runner has been executed.

### Task 6: Implement canonical-report.js

**Files:**
- Create: `scripts/canonical-report.js`

- [ ] **Step 1: Write canonical-report.js**

The report script:
1. Reads all frozen logs for a cenario
2. Reads the fixture to get invariant names
3. Runs invariants from `tests/scenarios/invariants.js`
4. Outputs comparison table to terminal (with ANSI colors)
5. Saves `report.json` and `report.md` alongside the frozen logs

**Terminal output format** (per spec Section 10):
- Header: cenarioId, versao, hash, date
- Metrics table: latencia, tokens (if available), turnos, erros parse — per model
- Invariants table: each invariant x each model (pass/fail)
- Detailed failures: turno, expected, received
- Verdict per model
- Summary line

**CLI:**
```bash
node scripts/canonical-report.js 01-combate-basico    # one scenario
node scripts/canonical-report.js --all                 # all scenarios
```
